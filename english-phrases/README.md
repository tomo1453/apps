# 英語フレーズ集

実際に使える英語表現を「言えるようになるまで」覚えるフラッシュカードWebアプリです。
iPhoneのChromeで開き、共有メニューの「ホーム画面に追加」でアプリのように使えます。

## 使い方
- カードの表：日本語の意味と使う場面 → タップで裏返すと英語フレーズと似た言い方
- 🔊 で英語（en-US）を読み上げ
- **まだ**：数枚後にもう一度出題
- **覚えた**：5日後 → 10日後 → 14日後に確認。3回続けて「覚えた」なら「知ってる」へ。途中で「まだ」なら通常の出題に戻る
- **知ってる**：今後は出題しない（「一覧」から出題に戻せる）
- 確認の期限を過ぎたフレーズは、次に開いたときに最優先で出題
- 上部の「覚えた」は「確認中」＋「知ってる」の合計

学習記録はブラウザの localStorage に保存されます（端末ごと）。

## フレーズの追加
`phrases.json` の `phrases` 配列に追加してください。`id` は重複しない文字列にします（学習記録のキー）。

```json
{ "id": "work-031", "cat": "work", "scene": "会議", "ja": "日本語の意味", "note": "使う場面のメモ", "en": "English phrase", "alt": "Similar expression" }
```

カテゴリを増やす場合は `categories` に `{ "id", "name", "emoji", "color" }` を追加します。

## ローカルで動かす
`phrases.json` を読み込むため、Webサーバー経由で開いてください。

```sh
cd english-phrases && python3 -m http.server 8000
```

### 場面イラスト
カード表面のイラストは `illust.js` がSVGで描きます。
- 背景と相手役：`scene`（会議・メール・電話・交渉・雑談・意見を言う・聞き返す・空港・ホテル・レストラン・トラブル・自己紹介・経歴説明・志望動機・逆質問）
- 主人公の表情：`mood`（`smile` / `happy` / `think` / `surprised` / `sorry` / `worried` / `confident`）
- 吹き出しの絵文字：`icon`
- 自分で用意した画像を使う場合は `"image": "images/xxx.png"` を指定（イラストより優先）
